# AirDisplay 原生控制面板改造方案

状态：原生面板改造、本地验证、签名校验和安装外观检查已完成。设计约定只保存在 `.impeccable.md`，没有同步到 `AGENTS.md`。

## 目标与边界

面向个人日常三屏使用，以 macOS 原生、克制、清晰、安静为方向。打开面板后先知道 Air 是否连接、能否输入、是否需要操作；高级选项保持可发现，但不占据日常界面的主要位置。

沿用 AppKit 原生面板、菜单栏入口、系统浅深色及控件行为，不引入网页容器、字体依赖或第三方界面库。恢复状态机、连接事件触发、输入锁、签名、Receiver 和线上协议不变。界面不得把正常拓扑或开始推流写成“画面已验证”。

## 信息层级

1. 顶部为 AirDisplay 名称及简短连接状态。连接、等待、恢复中、等待画面确认、失败分别呈现，不用颜色作为唯一状态提示。
2. 连接信息集中展示当前实际可用的数据：Air 接收端状态、显示规格、雷雳连接和输入状态。不得用显示器数量猜测 iPad 已正确显示，也不读取或展示设备个人名称。
3. 日常设置保留自动恢复、Air 键鼠、断线时移除虚拟屏和登录启动，使用原生控件、短标签和必要的次级说明。
4. 高级与诊断默认收起：4:4:4、性能统计、本机回环、测试标记和实验恢复方式。已有功能保持可达，不删除动作或偏好。
5. 恢复时在连接状态下方自动展开当前阶段及下一项操作；首次恢复方式选择、取消、失败重试和仅恢复 AirDisplay 都保留。待确认时直接展示三项动态画面核对与恢复输入按钮，不藏进高级区域。

## 结构示意

```text
AirDisplay
● Air 已连接                  [暂停显示]
  雷雳网桥 · 当前显示规格
  输入可用 / 输入已暂停

连接设置
  随航重连后自动恢复             [开关]
  使用 Air 的键盘和触控板         [开关]
  Air 断开时收回桌面             [开关]
  登录时启动                    [开关]

▸ 高级与诊断

恢复中或需要确认时：
  当前阶段 + 一句操作说明
  必要的等待 / 取消 / 重试操作
  三屏动态画面确认（到相应阶段才出现）
```

示意中的“已连接”“输入可用”均为状态示例，实际文案必须来自当前控制器数据。UI 状态采用明确的数据字段，不解析既有中文状态字符串来判断业务状态。

## 视觉与交互

- 系统窗口背景、语义文字颜色、系统强调色和细分隔线；布局本身建立层级，不为每块内容增加卡片、阴影或装饰渐变。
- 按已确认的原生工具方向使用系统字体和原生按钮。标题约 18 点，正文约 13 点，辅助信息约 11–12 点；只有需要对齐的统计数字使用等宽数字。
- 初始宽度约 520 点，普通状态尽量控制在约 400–460 点高；恢复状态按内容增长，超过可视区域时滚动。验证最小宽度、长中文、多行错误和完整恢复步骤，不能靠截断隐藏必要操作。
- 关键主操作保持单一。关闭显示、测试、本机回环和退出不与确认恢复输入争夺视觉优先级；主操作的可用性继续由实际状态控制。
- 状态刷新保持控件位置和用户展开状态，不抢键盘焦点。保留键盘操作、VoiceOver 标签、禁用态和首击行为。

## 文件范围与验证

- `Sender/Sources/ControlPanel.swift`：布局、视觉与披露交互，必要的小型界面数据类型放在同文件。
- `Sender/Sources/AppDelegate.swift`：仅调整给面板提供的状态字段和设置分组，不改生命周期或恢复规则。
- `Tests/ControlPanelTests.swift`：离屏验证状态、折叠、高级功能可达、键盘和辅助标签、长文及浅深色布局；预览继续放在被忽略的 `build/`。
- `.impeccable.md`：已确认设计上下文的唯一主记录；是否向 `AGENTS.md` 同步，由用户选择。

实施后运行项目约定的恢复回归、离屏界面检查、Sender 构建、签名校验和文档检查。先展示正常、恢复中、待确认及失败状态的离屏预览，再安排切换当前安装；不把静态预览当作真实三屏验证。

## 实施记录（2026-10-26）

- 面板首屏采用简短连接标题、显示规格、输入状态和自动恢复状态，提供一个普通显示控制；日常连接设置保留原有偏好键与动作，高级诊断默认折叠。
- 新增结构化 UI 状态字段，不解析中文文案。恢复和暂停状态会覆盖普通输入提示，并禁用普通显示控制；最终确认仍要求当前流的三项勾选，只有当前可执行主操作接收 Return 快捷键。
- 4:4:4、本机回环、测试标记、原始诊断和性能统计均可通过高级区域访问。定时刷新保留展开选择；长中文可换行，窗口保持可滚动，面板高度按内容调整。
- 使用系统字体、语义颜色和原生控件，没有新增界面依赖；恢复状态机、传输及输入注入实现没有改动。
- 本地恢复回归 172 项、离屏面板 158 项检查通过。面板检查包含浅深色、普通/恢复/确认/暂停状态、最小宽度长错误、折叠可达性、键盘主操作、披露按钮辅助标签和旧流确认失效。离屏原生控件预览使用实际约束与 cell 副本绘制，存放在本地忽略的构建目录，不是运行中 App 截图。
- Sender 构建通过，无代码并发警告。已备份旧版并安装新版；固定签名身份保持一致，严格签名校验通过，安装后的可执行文件与构建产物哈希一致。
- 运行中原生面板已检查：Air 连接、输入开启和随航监测状态显示正确；高级区域可展开，原有诊断操作可见，日常界面默认收起。此轮没有重新进行完整三屏故障恢复实测，不以构建、预览或面板连接提示代替逐屏动态画面验收。
